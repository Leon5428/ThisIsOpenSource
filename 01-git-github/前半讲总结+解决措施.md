## 解决措施

多亏了豆姐，快睡觉了想起来豆姐在推荐产品这方面确实无人能敌，我就把我遇到的问题喂给了豆姐，然后豆姐给我推荐了好几款软件，如下：

针对鼠标在两个屏幕之间游走这个问题呢，我决定使用pympress(https://github.com/Cimbali/pympress.git)，然后直接把讲稿做成pdf注释，这样大屏幕放课件pdf，我的笔记本屏幕可以查看注释查看页码查看时间，这样播放ppt的时候基本鼠标就可以停留在我的笔记本屏幕而不是大屏幕，减少了鼠标的移动。

OK我刚才体验了一下这个软件，夯爆了。现在还有一个问题就是演示的时候鼠标还会来回移动，这个该怎么解决呢？我目前打算使用微软自带的鼠标工具Find My House([https://github.com/microsoft/PowerToys.git](https://github.com/microsoft/PowerToys))，先用着看看效果。

最后的问题是在演示的时候，因为那个屏幕在我的背后，我不能很好的知道屏幕上是什么，这就导致演示很慢，这个我刚才尝试了一下OBS，把演示的大屏做一个回显在自己的电脑屏幕上，我突然发现OBS可以做窗口采集，这样的话，我就可以只在自己的笔记本屏幕上操作，然后让OBS把窗口采集到大屏幕，这样基本不用让鼠标在两个屏幕之间来回移动。

出了一些问题，OBS无法采集到Git Bash窗口，但是我可以直接采用全屏采集，然后直接把全屏采集的窗口投到大屏幕上，这样大屏幕只需要做两个窗口的切换，就是pympress窗口和OBS全屏采集窗口之间的切换。

使用上面的工具基本可以把鼠标一直限制在笔记本的屏幕内，不会出现太大的问题。我一会把这个写进README。
