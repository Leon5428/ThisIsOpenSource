# ThisIsOpenSource!
山东大学网络空间安全学院的开源入门课程，帮助学习者理解开源理念、掌握协作工具并参与真实的开源项目。

## 00-introduction：从操作系统到开源

《这就是开源》的第一讲。从日常使用场景出发，认识操作系统的作用，沿着 Unix、GNU 与 Linux 的发展脉络，了解自由软件与开源运动，建立学习后续工具与协作方法所需的背景知识。

涵盖了：

- **为什么需要操作系统**：认识处理器、内存与存储设备，理解操作系统如何协调程序与硬件资源。
- **操作系统的发展**：了解操作系统的发展历程与主要分类，以及 Unix 的诞生与影响。
- **GNU 与 Linux**：从GNU计划到Linux 内核，再到Linux 发行版，了解它们之间的联系。
- **从自由软件到开源**：初步认识自由软件与开源软件的理念，以及社区协作的价值。

课程资料：[课件 PDF](00-introduction/00-introduction.pdf) · [LaTeX 源码](00-introduction/00-introduction.tex)

## 01-git-github：Git 与 GitHub

《这就是开源》的第二讲。从 Linux 内核早期的协作方式说起，认识版本控制系统要解决的问题，完成 Git 的安装与配置，理解工作区、暂存区与版本库的关系，并完成第一次提交。远程仓库与 GitHub 协作部分尚在准备中。

涵盖了：

- **Git 的诞生**：从邮件补丁与 diff，到失去 BitKeeper，再到 Linus 自己动手写一个版本控制系统。
- **版本控制系统**：记录修改、比较差异、恢复版本、追踪作者，以及协调多人共同开发。
- **安装与配置**：Git 的安装选项，以及提交者姓名与邮箱的配置。
- **基本原理**：仓库、工作区、暂存区与版本库，以及 git add 与 git commit 各自做了什么。
- **基本操作**：git status、git add、git commit 与 git log。

课程资料：[课件 PDF](01-git-github/01-git-github.pdf) · [LaTeX 源码](01-git-github/01-git-github.tex)
