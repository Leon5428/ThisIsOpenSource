# ThisIsOpenSource!
山东大学网络空间安全学院的开源入门课程，帮助学习者理解开源理念、掌握协作工具并参与真实的开源项目。

## 00-introduction：从操作系统到开源

《这就是开源》的课程导论。从计算机硬件与日常使用场景出发，认识操作系统的作用，沿着 Unix、GNU 与 Linux 的发展脉络，了解自由软件与开源运动，建立学习后续工具与协作方法所需的背景知识。

计划涵盖：

- **为什么需要操作系统**：认识处理器、内存与存储设备，理解操作系统如何协调程序与硬件资源。
- **操作系统的发展**：了解操作系统的发展历程与主要分类，以及 Unix 的诞生与影响。
- **GNU 与 Linux**：区分 GNU 项目、Linux 内核与 Linux 发行版，了解它们之间的联系。
- **从自由软件到开源**：初步认识自由软件与开源软件的理念，以及社区协作的价值。

## 01-GitHub：认识开源协作平台

从浏览一个开源项目开始，认识 GitHub 上的项目结构与协作方式。通过阅读项目说明、查找使用文档和了解贡献流程，学习如何从开源软件的使用者逐步走向参与者。

建议涵盖（待完善）：

- **Git 与 GitHub**：区分版本控制工具与代码托管、协作平台，理解它们各自的作用。
- **读懂一个仓库**：认识 README、许可证、源码目录与贡献指南，找到使用和参与项目所需的信息。
- **发现与使用项目**：围绕实际需求查找项目，阅读文档，了解项目的使用条件。
- **参与交流与贡献**：认识议题（Issue）、仓库派生（Fork）、拉取请求（Pull Request）与代码审查（Code Review），了解反馈问题和提交改进的基本流程。
- **协作礼仪**：提问前查阅已有资料，清晰描述问题，尊重项目规范与贡献者。
